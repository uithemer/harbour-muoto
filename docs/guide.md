# Using Muoto

Muoto lets you customize icons, fonts, and display density on Sailfish OS.

## Before a system update

Revert themes and display-density changes **before** updating Sailfish OS. If you forgot, open Muoto: on the home mosaic open **Icons** and **Fonts**, select stock (Default), and apply; then open **Display density** and use **Restore default**.

## Main window

The app opens on a mosaic of tiles:

* **[Themes](themes)** — **Icons** and **Fonts** tiles open configure pages to apply packs, style missing icons, restore to stock, and uninstall
* **[Dynamic icons](dynamic-icons)** — live clock and calendar on the homescreen
* **[Display density](density)** — pixel ratio, launcher icon size

## Cover

The app cover shows the active icon/font pack when set. After applying from the main UI, the cover can reflect your choices.
